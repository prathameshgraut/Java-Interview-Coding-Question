# ☕ Java Interview Questions

## 📌 About Repository
This GitHub repository contains **most important Java Interview Questions** with **practical programs**.
It is designed for **students, freshers, and Java developers** to prepare for **technical interviews** and quick revision.
All questions are organized from **Basic to Advanced level**, and can be easily added and executed in **Eclipse / IntelliJ / VS Code**.

---------------------------------------------------------------------------------------------------------------------------------------------------------------------
## 🧠 Topics Covered
### 🔹 Basic Level
* Java Basics (Syntax, Data Types, Operators)
* Control Statements (if, switch, loops)
* Array's Program
* Strings Program
* Recursion (Prime Number, Factorial, Fibonacci, etc.)

### 🔹 Patterns
* Star Patterns
* Number Patterns
* Table Patterns

### 🔹 Collections Framework
* ArrayList
* LinkedList
* HashSet
* HashMap
* Difference between List, Set, Map

### 🔹 Advanced Level
* JDBC Architecture
* JDBC CRUD Operations (Insert, Update, Delete, Select)
* MySQL Database Connectivity
* Exception Handling with JDBC

## ▶️ How to Use
1. Clone the repository
   ```bash
   git clone https://github.com/your-username/java-interview-questions.git
   ```
2. Open the project in Eclipse / IntelliJ
3. Run `.java`    files using         `Run As → Java Application`
4. Add your own interview questions easily
